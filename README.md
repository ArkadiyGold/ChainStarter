# ChainStarter

Децентрализованная краудфандинговая платформа на блокчейне. Web3-аналог Kickstarter, где сбор и распределение средств регулируются смарт-контрактами.

##  Быстрый запуск

```bash
# В терминале, находясь в папке проекта:
docker compose up --build
```

После запуска откройте в браузере: **http://localhost:8501**

##  О проекте

ChainStarter решает проблемы традиционных краудфандинговых платформ:
-  **Trustless Escrow** — средства в смарт-контракте, а не у платформы
-  **Автоматический возврат** — при недостижении цели
-  **Прозрачность** — все транзакции видны в блокчейне
-  **Глобальность** — участие из любой точки мира без банков
-  **Аналитика на основе блокчейна** — данные поступают из событий смарт-контракта

##  Архитектура

```
Smart Contract (Solidity/Hardhat)
        ↓ события
Ingestor (Python + Web3.py)
        ↓
PostgreSQL (raw_events → campaigns → marts)
        ↓
Streamlit (дашборд с графиками)
        ↓
Docker Compose (запуск одной командой)
```

##  Ключевые функции

### Смарт-контракт
- `createCampaign(goal, duration)` — создание кампании
- `fund(campaignId)` — внесение вклада
- `claim(campaignId)` — вывод средств автором (при успехе)
- `refund(campaignId)` — возврат средств спонсорам (при провале)

### События блокчейна
- `CampaignCreated` — создана новая кампания
- `Contributed` — внесён вклад
- `Refunded` — возврат средств
- `FundsClaimed` — автор забрал средства

### Аналитический дашборд
1. **Статистика кампаний** — успешные/провальные
2. **Топ-5 спонсоров** — рейтинг по сумме вкладов
3. **Последние события** — сырые данные из блокчейна

##  Тестовые данные

Симулятор `simulate.py` генерирует:
- 100 кампаний с разными целями
- 500 вкладов от 20 случайных аккаунтов (0.1–2 ETH)
- **Итого: 600 событий в блокчейне**

##  Как это работает

1. **Смарт-контракт** генерирует события при создании кампаний и внесении вкладов
2. **Инжестор** (Web3.py) слушает события и записывает их в PostgreSQL
3. **SQL-витрины** (`mrt_campaign_stats`, `mrt_top_sponsors`) агрегируют данные
4. **Streamlit** читает витрины и строит интерактивные графики

> **Ключевой принцип:** «Данные в аналитике появляются только потому, что смарт-контракт сгенерировал события. Без блокчейна нет данных».

##  Использование

### Создание кампании (через дашборд)
1. Откройте http://localhost:8501
2. Перейдите на вкладку «Создать кампанию»
3. Введите цель (ETH) и длительность (дни)
4. Нажмите «Создать»

### Проверка данных
```sql
-- Подключитесь к PostgreSQL (порт 5433)
SELECT COUNT(*) FROM raw_events;           -- Должно быть 600+
SELECT * FROM mrt_campaign_stats;          -- Статистика кампаний
SELECT * FROM mrt_top_sponsors;            -- Топ спонсоров
```

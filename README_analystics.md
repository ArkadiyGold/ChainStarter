# ChainStarter

Децентрализованная краудфандинговая платформа на блокчейне. Web3-аналог Kickstarter, где сбор и распределение средств регулируются смарт-контрактами, а не централизованным посредником.

##  О проекте

### Проблема
Традиционные краудфандинговые платформы (Kickstarter, Planeta.ru) имеют ряд недостатков:
- Платформа удерживает средства и берёт комиссию 5–10%
- Возврат при провале зависит от честности посредника
- Платформа может заблокировать проект
- Нет прозрачности использования средств
- Ограничения по географии и банковским системам

### Решение
ChainStarter использует смарт-контракты для замены посредника:
- **Автор** публикует идею с указанием цели и дедлайна
- **Сообщество** вносит средства, которые блокируются в контракте
- **Цель достигнута** → автор забирает средства и реализует проект
- **Цель не достигнута** → спонсоры автоматически получают возврат
- **Все транзакции** публичны и неизменяемы

## 🚀 Установка и запуск

### Предварительные требования

- **Node.js 18+** и npm
- **Python 3.10+**
- **PostgreSQL 18**
- **Git**

### 1. Клонирование репозитория

```bash
git clone <repository-url>
cd chainstarter-contracts
```

### 2. Установка зависимостей

**Node.js (для смарт-контракта):**
```bash
npm install
```

**Python (для бэкенда):**
```bash
cd backend
python -m venv .venv
.\.venv\Scripts\Activate.ps1  # Windows
# source .venv/bin/activate   # Linux/Mac
pip install -r requirements.txt
cd ..
```

### 3. Запуск локальной блокчейн-сети

В отдельном терминале:
```bash
npx hardhat node
```

### 4. Деплой смарт-контракта

В новом терминале:
```bash
npx hardhat run scripts/deploy.js --network localhost
```

Сохраните адрес развёрнутого контракта — он понадобится для инжестора.

### 5. Создание базы данных

Подключитесь к PostgreSQL и создайте базу:
```sql
CREATE DATABASE chainstarter;
```

Затем выполните SQL-схемы:
```bash
cd backend
psql -U postgres -d chainstarter -f schema.sql
psql -U postgres -d chainstarter -f marts.sql
```

### 6. Запуск инжестора

В терминале с активированным виртуальным окружением:
```bash
cd backend
python ingest.py
```

Инжестор начнёт слушать события блокчейна и записывать их в базу данных.

### 7. Запуск аналитического дашборда

В новом терминале:
```bash
cd analytics
python -m venv venv
.\venv\Scripts\Activate.ps1  # Windows
pip install streamlit pandas matplotlib psycopg2-binary sqlalchemy
streamlit run dashboard.py
```

Дашборд откроется в браузере по адресу `http://localhost:8501`.

## 📊 Использование

### Создание кампании

```bash
npx hardhat run scripts/create-campaign.js --network localhost
```

### Просмотр данных

- **Сырые события:** таблица `raw_events` в PostgreSQL
- **Статистика кампаний:** VIEW `mrt_campaign_stats`
- **Топ спонсоров:** VIEW `mrt_top_sponsors`
- **Визуализация:** Streamlit-дашборд

### Ключевые события смарт-контракта

| Событие | Описание |
|---------|----------|
| `CampaignCreated` | Создана новая кампания |
| `Contributed` | Внесён вклад в кампанию |
| `Refunded` | Возврат средств спонсору |
| `FundsClaimed` | Автор забрал собранные средства |

## 🔑 Ключевые принципы

1. **Trustless Escrow** — средства блокируются в смарт-контракте, а не у платформы
2. **Автоматический возврат** — не зависит от честности посредника
3. **Прозрачность** — все транзакции видны в блокчейне
4. **Глобальность** — любой может участвовать без привязки к банковской системе
5. **Аналитика на основе блокчейна** — данные появляются только потому, что смарт-контракт генерирует события
